📌 1. Project Overview

Customer Lifetime Value (CLV) is an important business metric that helps organizations understand the long-term value generated by their customers.

This project explores e-commerce customer data using Python, statistical analysis, and data visualization. It includes 33+ visualizations to analyze customer demographics, spending patterns, geographical distribution, customer loyalty, and CLV-related insights.

The primary goal is to transform raw customer data into meaningful insights that support better customer understanding and data-driven business decisions.
