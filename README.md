### 📌 Project Overview
This project analyzes e-commerce customer data using **33+ visualizations** to identify customer trends, understand spending behavior, and generate meaningful business insights.

### 📂 Dataset
- 📄 **File:** `E-commerce_Customer_Segmentation_2.csv`
- 👥 **Records:** 1,000+ customers
- 📈 **Features:** Customer demographics, annual income, spending score, purchase history, product categories, geographical details, loyalty indicators, and CLV scores.

### 🔍 Key Analysis
- 👤 **Customer Demographics** — Age, gender, and spending patterns.
- 🌍 **Geographical Analysis** — Country-wise revenue and city-level customer distribution.
- 🎯 **Customer Segmentation** — RFM analysis, spending behavior, and loyalty patterns.
- 💰 **Revenue Analysis** — Customer spending trends and revenue distribution.
- 💎 **CLV Analysis** — High-value customer identification and CLV insights.
- 📊 **Data Visualization** — 33+ charts, correlation heatmaps, and CLV comparisons.

### 🛠️ Technologies Used
- 🐍 Python
- 🧮 Pandas & NumPy
- 📊 Matplotlib & Seaborn
- 📉 Plotly
- 📓 Jupyter Notebook
